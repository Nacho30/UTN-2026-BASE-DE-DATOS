-------------------------------------------------------------------
 Nested Loop
   ->  Nested Loop
         ->  Index Scan using pedido_pkey on pedido p
               Index Cond: (id_pedido = 1)
         ->  Index Scan using cliente_pkey on cliente c
               Index Cond: (id_cliente = p.id_cliente)
   ->  Hash Join
         Hash Cond: (pr.id_producto = pp.id_producto)
         ->  Seq Scan on producto pr
         ->  Hash
               ->  Bitmap Heap Scan on pedido_producto pp
